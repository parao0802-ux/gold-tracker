# 금시세 트래커

국제 금·은 현물 시세를 원화로 환산해 보여주고, 직접 입력한 매수 기록으로
투자 현황을 계산하는 대시보드입니다.

빌드 도구도 서버도 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `styles.css` | 디자인 토큰 + 레이아웃 (라이트/다크) |
| `app.js` | 시세 조회, 손익 계산, 차트 |

## 기능

**실시간 시세** — 순금 24K 1g / 1돈(3.75g), 은 1g, 원/달러 환율.
1분마다, 그리고 탭으로 돌아올 때마다 자동 갱신됩니다.

**금시세 차트** — 순금 1g 원화 시세의 실제 일별 기록. 1개월 / 3개월 / 1년을
고를 수 있고, 기간 등락률이 함께 표시됩니다. 그래프에 마우스를 올리면
그날의 1g·1돈 값이 나옵니다. 마지막 점은 오늘 실시간 시세로 이어 붙입니다.

**투자 현황** — 현재 평가액, 투자 원금, 평가 손익, 수익률, 보유 순금 환산 중량,
평균 매입가, 본전 시세(순금 1돈 기준 손익분기점).

**자산 추이** — 사이트가 시세를 받아올 때마다 스냅샷이 한 점씩 쌓이고,
그 위에 평가액과 투자 원금을 함께 그립니다. 그래프에 마우스를 올리면
그 시점의 값이 보입니다.

**건별 수익률** — 매수 건마다 0%를 기준으로 이익(빨강)·손실(파랑)을 비교합니다.
기록이 2건 이상일 때만 나타납니다.

**매수 기록** — 매수일, 품목(금/은), 순도(24K~14K, 925), 수량(돈/g/oz/kg),
총 매수 금액, 메모. 수정·삭제, JSON·CSV 내보내기, JSON 가져오기를 지원합니다.

## 계산 방식

- 1 트로이온스 = 31.1034768 g, 1돈 = 3.75 g
- 순물질 환산 그램 = 수량 × 단위계수 × 순도
  (예: 18K 3돈 → 3 × 3.75 × 0.75 = 8.44g)
- 평가액 = 순물질 그램 × (해당 금속의 g당 원화 시세)
- g당 원화 시세 = (USD/트로이온스) × (원/달러) ÷ 31.1034768

## 시세 출처

| 데이터 | 출처 | 비고 |
|---|---|---|
| 금·은 현물가 (USD/oz) | `api.gold-api.com` | API 키 불필요 |
| 원/달러 환율 | `api.frankfurter.dev` | ECB 고시 기준 |
| 환율 예비 | `open.er-api.com` | 위 API 실패 시 자동 전환 |
| 과거 금시세 (1년) | `api.nbp.pl` + `api.frankfurter.dev` | 아래 설명 참고 |

시세를 받아오지 못하면 마지막으로 받은 값을 그대로 표시하고 상단에 알림이 뜹니다.

### 과거 금시세를 만드는 방법

무료로 쓸 수 있고 CORS까지 열린 금 시세 **히스토리** API가 사실상 없어서,
폴란드 중앙은행(NBP)을 경유합니다. NBP는 LBMA 고시가를 매일
**PLN/그램(순도 1000)** 으로 공개합니다.

```
원화 g당 시세 = (NBP 금시세 PLN/g) × (그날의 PLN→KRW 환율)
```

환율은 영업일에만 고시되므로, 해당 날짜 이하의 가장 최근 값을 이어서 씁니다.
라이브 현물가와 대조하면 오차는 1.5% 안쪽입니다 (LBMA 고시가와 실시간
현물가의 시점 차이, 환율 반올림 때문). 추세를 보기에는 충분하지만
**정밀한 가격 조회용은 아닙니다.**

하루 한 번만 받아 localStorage에 캐시하므로, 같은 날 여러 번 열어도
네트워크 요청은 한 번뿐입니다.

**은은 과거 차트가 없습니다.** NBP가 은은 고시하지 않고, 키 없이 쓸 수 있는
다른 은 히스토리 API를 찾지 못했습니다. 은은 현재 시세만 표시합니다.

> **국제 현물가 기준입니다.** 한국금거래소 등 국내 소매 가격은 여기에
> 세공비·유통 마진·부가세가 붙어 더 비싸고, 되팔 때(매입가)는 더 쌉니다.
> 실제 거래 가격이 아니라 시세 흐름을 보는 용도로 쓰세요.

## 데이터 보관

매수 기록과 시세 스냅샷은 브라우저의 **localStorage에만** 저장됩니다.
서버로 전송되지 않고, 다른 기기와 동기화되지도 않습니다.

- 브라우저 데이터를 지우면 기록도 사라집니다. **JSON 내보내기로 정기 백업하세요.**
- 다른 기기로 옮기려면 JSON을 내보낸 뒤 그 기기에서 가져오기 하면 됩니다.
